# Animated De Bruijn comparison

This static widget overlays the exact `kmax=1` De Bruijn construction as
unfilled outlines and the trained transformer prediction as filled rhombi.
Inference runs in the browser through ONNX Runtime Web. WebGPU is preferred;
WASM is used automatically when WebGPU is unavailable.

## Run

```bash
cd web
npm install
npm run dev
```

Open the URL printed by Vite. Use `npm run build` to write the deployable site
to `web/dist/`.

The page starts with the more accurate `256 × 16` model, whose browser asset
is approximately 49 MiB. The first load can therefore take noticeably longer.
The model selector can switch to the compact `32 × 4` model.

Two live phase-space plots show `(γ0, γ1)` and `(γ2, γ3)` with short trajectory
trails. `γ4` remains part of the model condition but is intentionally omitted
from the display. The **rotation** selector either holds the underlying
`θoffset=0.5` or continues the animated triangle wave. Both gamma plots use a
square aspect ratio and appear as compact, axis-free panels just outside the
animation's lower-right edge. The tiling renderer uses a fixed world view so the
comparison does not zoom as its geometry changes.

The separate **A Arcs** and **C Arcs** checkboxes draw the two Amethyst
matching-rule arc families on the neural geometry when it is visible. If the
neural layer is hidden, enabled arc families move to the exact algorithm
geometry instead.

## Animated condition

`T01` is a period-`2π` linear triangle wave moving `0 → 1 → 0`. On each page
load, `a0…a3` are sampled independently from `Uniform[0,1)` and remain fixed
until **New random phases** is pressed.

```text
γ0 = T01(t + a0)
γ1 = T01(t/φ + a1)
γ2 = (sin(t + a2) + 1)/2
γ3 = (sin(t/e + a3) + 1)/2
γ4 = mod(-(γ0 + γ1 + γ2 + γ3), 1)
θoffset = T01(t)
```

Thus every input remains in the range seen during training and `Σγ` is an
integer up to floating-point roundoff.

## Re-export models

The export script defaults to the retained epoch-50 `32 × 4` checkpoint and
best epoch-196 `256 × 16` checkpoint under
`cloud/runs/0824-penrose-debruim`.

```bash
~/.aivenv/bin/python -m pip install -r web/requirements-export.txt
~/.aivenv/bin/python web/export_models.py
```

Each export is checked with the ONNX checker and compared numerically against
the PyTorch result. The generated `public/models/manifest.json` records model
metadata, file sizes, SHA-256 checksums, and maximum parity errors.

## Tests

```bash
cd web
npm test
npm run build
```

The JavaScript tests include a fixture generated by `debruijn_numpy`, waveform
and phase-constraint checks, and rhombus-vertex center preservation.
